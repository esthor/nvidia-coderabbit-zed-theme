# NVIDIA x CodeRabbit Theme for Zed

A celebratory theme for [Zed](https://zed.dev) honoring the collaboration & partnership between NVIDIA and CodeRabbit.

[![NVIDIA](https://img.shields.io/badge/NVIDIA-76B900?style=for-the-badge&logo=nvidia&logoColor=white)](https://nvidia.com) [![CodeRabbit](https://img.shields.io/badge/CodeRabbit-FF570A?style=for-the-badge)](https://coderabbit.ai)

## About

This theme celebrates the collaboration between NVIDIA and CodeRabbit, marking the widespread adoption of CodeRabbit across thousands of internal code repositories at NVIDIA + the integration of **Nemotron 3 Nano**—NVIDIA's latest foundation model—as one of the frontier models in CodeRabbit's ensemble of AI models powering its agentic workflows for intelligent code review.

## Color Palette

The theme draws inspiration from both brands:

| Color | Hex | Usage |
|-------|-----|-------|
| NVIDIA Green | `#76B900` | Primary accent, cursor, success states |
| CodeRabbit Orange | `#FF570A` | Keywords, errors, emphasis |
| Teal | `#25BAB1` | Types, properties, links, hints |
| Yellow | `#F0DF22` | Constants, numbers, warnings |
| Pink | `#F2B8EB` | Enums, variants, renamed items |
| Light Green | `#8cd633` | Strings |

## Installation

### From Zed Extensions (Recommended)

1. Open Zed
2. Open the Extensions panel (`cmd+shift+x` on macOS, `ctrl+shift+x` on Linux)
3. Search for "NVIDIA CodeRabbit"
4. Click Install

### Manual Installation

1. Clone this repository
2. Copy the `themes` folder to your Zed extensions directory
3. Restart Zed
4. Select the theme from Settings > Theme
